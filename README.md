# Kellystão

Veja rumores, negociações e sondagens apontadas para o elenco do Flamengo. Atualizado para ajudar torcedores, criadores de conteúdo e imprensa esportiva. 

A ideia da listar as especulações começou com o amigo Kelyson Aguilar, e então o Guga Alves teve a ideia de transformar isso em um site para a livre consulta de todos.

Vale citar que o conteúdo está em constante evolução, e estamos aos poucos catalogando as fontes.
